# Compiler 3-5 分钟演示视频脚本

目标时长：约 3 分 10 秒。主线只完整演示一次，其他世界快速切换，证明同一编译器可跨世界工作且拥有独立战略地图。

| 时间 | 画面 | 旁白重点 |
| --- | --- | --- |
| 0:00-0:08 | 海报标题 | Compiler 不是一套固定塔防关卡，而是把自然语言构想编译成可玩内容的游戏系统。 |
| 0:08-1:30 | 《长夜灯火》世界配置、战略地图、工坊与首战 | 世界书、当前进度、材料和敌情组成编译上下文；样品通过激活门后进入战斗。 |
| 1:30-1:41 | 仙侠独立云海战略地图 | 同一编译器将世界观约束投影成新的节点、资源和研发语境。 |
| 1:41-1:54 | 西幻独立沼泽堡垒战略地图 | 世界内容与视觉资产随世界实例变化，运行时协议保持不变。 |
| 1:54-2:08 | 科幻独立轨道设施战略地图 | 扩展世界不是换文案或复用《长夜灯火》地图，而是独立运行包。 |
| 2:08-2:33 | 三世界对照页 | 同一协议驱动三种世界观，地图背景、节点与内容均独立。 |
| 2:33-3:01 | DAG 架构与安全门 | 模型不能直接执行；只有通过 Schema、行为 ABI、模拟和激活门的产物才能进入运行时。 |
| 3:01-结束 | 海报收尾 | 玩家负责想象，Compiler 把想象变成规则内真正能玩的东西。 |
